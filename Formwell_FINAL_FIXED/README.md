# Formwell – image-fixed SEO build

## Use
Extract the ZIP and run `index.html` with VS Code Live Server or deploy the folder to Vercel/Cloudflare Pages.

## Images
The site uses the 30 images supplied in the uploaded ZIP. They are converted to optimized WebP assets and referenced with working paths. Six exercise visuals are distinct crops/variants so the exercise pages do not all share the same image.

## Important
The image files were supplied by the website owner; license/copyright ownership was not independently verified.

Before production, replace `YOUR-DOMAIN.com` in `robots.txt` and set `SITE_CONFIG.siteUrl` if you want absolute canonical/schema URLs during local/static rendering.
